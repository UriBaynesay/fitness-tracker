# Fitness Tracker handoff bundle

Everything designed so far, ready to drop into the server project.

| Path | What it is |
| --- | --- |
| `CLAUDE.md` | Project brief for Claude Code: decisions made, working style, milestone 1 scope. Copy it to the root of the repo. |
| `docs/spec.md` | Full spec: scope, architecture, data model, flows (including the overload hint rules), API, security, roadmap. |
| `design/DESIGN.md` | Colors, fonts, sizes and a description of all ten screens. |
| `design/screens/*.dc.html` | The ten screen mockups, as HTML source (390 × 844). Readable as text. |
| `design/canvas.json` | Layout of those screens on the design canvas. |
| `seed/exercises-seed.json` | 62 exercises with English and Hebrew names, muscle group, equipment and a timed flag. |

## How to continue

1. Put this folder in the server project (for example `docs-handoff/`), and copy `CLAUDE.md` to the repo root.
2. Start Claude Code in plan mode and say: "Read CLAUDE.md, then docs/spec.md and design/DESIGN.md. Plan milestone 1 (foundation) for my VPS and wait for my approval."
3. Move through the roadmap in `docs/spec.md`, one milestone at a time.
